# SiteCraft v1.0.0 — سایت‌ساز نیکا

**SiteCraft** یک سایت‌ساز بصری فارسی است که به شما کمک می‌کند بدون نوشتن مستقیم کد، بخش‌های یک وب‌سایت را بسازید، ویرایش کنید و خروجی HTML بگیرید.

## استفاده از SiteCraft

### ۱. اجرای آنلاین
[اجرای آنلاین SiteCraft](https://nikanazimi1393-design.github.io/sitecraft/)

### ۲. استفاده آفلاین
از بخش [GitHub Releases](https://github.com/nikanazimi1393-design/sitecraft/releases) نسخهٔ منتشرشده را دریافت کنید و فایل `index.html` را با یک مرورگر مدرن باز کنید.

## امکانات نسخهٔ 1.0.0

- ساخت صفحه‌های سایت و افزودن عنوان، متن، دکمه، لینک، تصویر و فاصله
- ویرایش متن، رنگ، اندازه و تراز بخش‌ها
- پیش‌نمایش زنده و جابه‌جایی یا حذف بخش‌ها
- ذخیرهٔ پروژه در حافظهٔ مرورگر
- **وارد کردن پروژه:** فایل پروژهٔ `.json` را برای ادامهٔ ویرایش کامل وارد کنید؛ همچنین می‌توانید فایل `.html` یا `.htm` را وارد کنید تا عنوان‌ها، متن‌ها، لینک‌ها و تصاویر پشتیبانی‌شده به بخش‌های قابل‌ویرایش تبدیل شوند. تبدیل HTML ممکن است ظاهر و CSS اصلی را دقیقاً حفظ نکند.
- **خروجی گرفتن از پروژه:** با دکمهٔ «خروجی گرفتن از پروژه» یک فایل JSON قابل انتقال و پشتیبان‌گیری دریافت کنید.
- دریافت خروجی HTML برای انتشار سایت
- رابط فارسی و راست‌چین؛ بدون نیاز به نصب وابستگی برای اجرای پایه

## انتقال پروژه بین دستگاه‌ها

1. در دستگاه اول، پروژه را باز کنید و روی «خروجی گرفتن از پروژه» بزنید.
2. فایل `.json` دریافت‌شده را به دستگاه دیگر منتقل کنید. (برای ادامهٔ ویرایش کامل، JSON بهترین گزینه است؛ HTML بیشتر برای واردکردن محتوای موجود است.)
3. SiteCraft را در دستگاه دوم باز کنید و «وارد کردن پروژه» را بزنید.
4. فایل JSON را انتخاب و جایگزینی پروژه فعلی را تأیید کنید.

**توجه:** وارد کردن پروژه، پروژهٔ فعلی را جایگزین می‌کند؛ پس پیش از آن، اگر لازم است از پروژهٔ فعلی خروجی بگیرید. فایل JSON پروژه با خروجی HTML فرق دارد: JSON برای ادامهٔ ویرایش در SiteCraft است و HTML برای انتشار سایت.

## اجرا و محدودیت‌ها

فایل `index.html` را در یک مرورگر مدرن باز کنید. SiteCraft با HTML، CSS و JavaScript ساخته شده است. ذخیرهٔ خودکار در حافظهٔ همان مرورگر انجام می‌شود؛ برای پشتیبان‌گیری یا انتقال به مرورگر/دستگاه دیگر از قابلیت خروجی و وارد کردن JSON استفاده کنید. قبل از انتشار، صفحات و لینک‌های خروجی را آزمایش کنید.
