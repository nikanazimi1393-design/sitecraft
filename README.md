# SiteCraft

**SiteCraft** یک پروژهٔ سایت‌ساز بصری و بدون کدنویسی است که هدفش این است هر کسی بتواند با ابزارهای ساده، وب‌سایت خودش را طراحی کند و در پایان خروجی HTML دریافت کند.

> وضعیت پروژه: نمونهٔ اولیه / در حال توسعه

## ایدهٔ پروژه

به‌جای نوشتن دستی کد، کاربر بخش‌های موردنیاز سایتش را اضافه می‌کند، آن‌ها را شخصی‌سازی می‌کند و عملکرد هر بخش را تنظیم می‌کند. در پایان، سایت‌ساز فایل‌های لازم برای وب‌سایت خروجی را تولید می‌کند.

## قابلیت‌های برنامه‌ریزی‌شده

- افزودن و ویرایش عنوان، متن، دکمه، لینک، تصویر و بخش‌های مختلف صفحه
- شخصی‌سازی رنگ‌ها، اندازهٔ متن، تراز و ظاهر عناصر
- تنظیم عملکرد دکمه‌ها، مانند بازکردن یک URL یا رفتن به صفحه‌ای دیگر
- ساخت و مدیریت چند صفحه
- پیش‌نمایش سایت هنگام طراحی
- خروجی گرفتن از وب‌سایت به‌صورت HTML
- آماده‌سازی خروجی برای انتشار روی GitHub Pages

## فناوری‌ها

- HTML
- CSS
- JavaScript

هدف این است که خودِ ویرایشگر نیز به‌صورت یک وب‌سایت استاتیک قابل اجرا و میزبانی روی GitHub Pages باشد.

## اجرای پروژه

پس از آماده‌شدن فایل‌های اصلی برنامه، می‌توان فایل index.html را در یک مرورگر مدرن باز کرد. برای انتشار آنلاین، فایل‌های پروژه را در مخزن GitHub قرار دهید و از مسیر Settings → Pages، شاخه و پوشهٔ انتشار را انتخاب کنید.

## مشارکت و بازخورد

این پروژه در مرحلهٔ توسعه است. پیشنهادها، گزارش خطاها و ایده‌های جدید برای بهترشدن تجربهٔ ساخت سایت بدون کدنویسی خوش‌آمد هستند.

## زبان

رابط کاربری پروژه می‌تواند فارسی و راست‌چین باشد؛ هدف این است که ساخت سایت برای کاربران فارسی‌زبان هم ساده و در دسترس باشد.
