# SiteCraft — نسخهٔ اولیه

**SiteCraft** یک سایت‌ساز بصری فارسی است که کمک می‌کند بدون نوشتن مستقیم کد، بخش‌های یک وب‌سایت را بسازی، ظاهرشان را ویرایش کنی و خروجی HTML بگیری.

> ⚠️ **توجه: این نسخه، نسخهٔ اولیه (Early Preview) است.** پروژه هنوز در حال توسعه است و ممکن است بعضی از ابزارها یا عملکردها درست کار نکنند، ناقص باشند یا در برخی شرایط نتیجهٔ مورد انتظار را ندهند. لطفاً انتظار یک نسخهٔ پایدار و کامل را نداشته باش.

**[دانلود نسخه‌ها از بخش Releases](https://github.com/nikanazimi1393-design/sitecraft/releases)**

## امکانات موجود در نسخهٔ اولیه

- افزودن بخش‌های عنوان، متن، دکمه، لینک، تصویر، فاصله و معرفی
- ویرایش متن، رنگ، اندازه و تراز بخش‌ها
- پیش‌نمایش سایت هنگام طراحی
- جابه‌جایی و حذف بخش‌ها
- ساخت، انتخاب و حذف صفحه‌های پروژه
- ذخیرهٔ پروژه در حافظهٔ مرورگر
- دریافت خروجی HTML برای صفحه‌ها

## محدودیت‌های شناخته‌شده

- بعضی ابزارها ممکن است هنوز کامل پیاده‌سازی نشده باشند یا درست عمل نکنند.
- ذخیره‌سازی پروژه در حافظهٔ همان مرورگر انجام می‌شود؛ پاک‌کردن داده‌های مرورگر یا استفاده از مرورگر/دستگاه دیگر می‌تواند باعث در دسترس نبودن پروژهٔ ذخیره‌شده شود.
- خروجی HTML چندصفحه‌ای باید با نام‌های مناسب در یک پوشه نگهداری شود تا لینک میان صفحه‌ها درست کار کند.
- پیش از استفاده از خروجی در یک وب‌سایت واقعی، همهٔ بخش‌ها و لینک‌ها را بررسی و آزمایش کن.

## اجرا

فایل `index.html` را در یک مرورگر مدرن باز کن. این پروژه با HTML، CSS و JavaScript ساخته شده و برای اجرای پایه به نصب وابستگی جداگانه نیاز ندارد.

## بازخورد و گزارش مشکل

اگر با ابزار خراب، نتیجهٔ اشتباه یا خطایی روبه‌رو شدی، لطفاً آن را گزارش کن. گزارش‌ها و پیشنهادها به بهترشدن نسخه‌های بعدی SiteCraft کمک می‌کنند.

## برنامهٔ توسعه

هدف نسخه‌های آینده، بهترکردن پایداری ابزارها، تجربهٔ ویرایش، مدیریت صفحه‌ها و خروجی گرفتن از سایت است. این موارد برنامهٔ توسعه‌اند و لزوماً در نسخهٔ فعلی کامل نیستند.
